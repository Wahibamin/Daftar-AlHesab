# دليل نشر المستودع — دفتر الحساب

1. أنشئ مستودعًا عامًا باسم **Daftar-AlHesab** أو `daftar-alhesab-flutter`.
2. **ارفع محتويات مجلد `Daftar_AlHesab` فقط، وليس ملف ZIP كملف وحيد**؛ يجب أن يظهر `README.md` في جذر المستودع.
3. ستظهر صور الواجهات تلقائيًا لأن الروابط نسبية إلى `screenshots/`.
4. لا تُضف ملفات `.local/` أو `backups/` أو `audit/` أو ملفات التوقيع والترخيص وقواعد البيانات الحقيقية.
5. راجع ملف README والصور بعد رفعها من صفحة المستودع وتأكد من ظهور الأسماء العربية بشكل صحيح.
6. أضف وصف GitHub التالي:

> دفتر الحساب | تطبيق Flutter محاسبي عربي لإدارة الفواتير والمخزون والعملاء والخزينة والتقارير، بتخزين SQLite محلي وواجهات Android فعلية.

**وسوم مقترحة:** `flutter` `dart` `sqlite` `android` `inventory-management` `accounting` `point-of-sale` `arabic-ui` `portfolio`.

## تنبيه حول الترخيص

هذا مستودع عرض أعمال. لم يُختر ترخيص مفتوح المصدر، لذا لا تُضف MIT أو Apache تلقائيًا. يظل ملكًا لصاحب المشروع ما لم يقرر ترخيصًا لاحقًا.

## ملاحظات المعاينة

- روابط الصور في Markdown القياسي تعمل على GitHub مباشرة.
- معاينات بعض تطبيقات الدردشة قد لا تعرض الصور المرتبطة بمسارات نسبية عندما يُفتح `README.md` وحده. افحصها داخل المستودع المنشور أو في معاين Markdown المحلية.
